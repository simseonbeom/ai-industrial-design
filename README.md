## 배포 (GitHub Pages)

빌드 과정 없이 정적 파일 그대로 배포됩니다.

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch` → Branch `main` / 폴더 `/ (root)` → **Save**
3. 잠시 후 `https://<계정>.github.io/<저장소>/` 에서 열립니다.
